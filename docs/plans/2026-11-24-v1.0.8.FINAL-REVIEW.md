## 2. Data safety across migration v3 (S1)

The SQL is at `crates/athanor-core/src/store/migrations.rs:85-132`.

- **Never deletes and never adds tending rows (#5).** The only statements on `tending` are `UPDATE … WHERE minutes = 0` (`:115-116`) and `UPDATE … WHERE thread_ids = '[]' AND EXISTS(…)` (`:117-121`). `created_at` is untouched. ✅
- **Realizations never mutated (#4).** v3 reads `realizations` (`:102-107`) and never writes it. The hand-walk below confirms it. ✅
- **Atomic and idempotent.** `migrate_with` wraps each entry with `BEGIN … PRAGMA user_version = N; COMMIT` and rolls back on error (`:154-171`). v3 runs once per file. A rerun is a no-op because `user_version` is 3, and a failure leaves the file at v2. Every `INSERT` is `OR IGNORE`, and every `UPDATE` is guarded on a placeholder value. ✅
- **Ghosts uncredited.** `minutes` and `tended_day` are set only for sessions that are `closed` and whose transcript carries the learner marker (`:94-98`). `v3_learner_marker_matches_transcript_module` pins the LIKE literal to `transcript.rs`. ✅

The existing-thread and honest-gap paths share that code. The mystagogue then links the parent as `fixed` and the child as `born` (`mystagogue/mod.rs:~190-193`). ✅ The code is right, but the honest-gap tests don't prove it; see T1.

## 3. Apple speech (Bellows)

- **Glue only (#1).** `AppleBellowsController.swift` handles capture, conversion, request plumbing and event forwarding. The latch, commit, rotation, self-close handling and turn end are all in `crates/stt/src/text_bellows/mod.rs`. Swift's only "decision" is to map `.unavailable` to `.permissionDenied` + `stop()` (`AppleBellowsController.swift:~250`). The silence latch constant (800 ms) is configuration handed to Rust. ✅
- **Permission denied → typed fallback, no nag.** Denied mic or speech, an on-device recognizer that is unsupported or unavailable, and a capture failure all yield `.permissionDenied`. `SessionScreen.swift:534-538` and `InitiationScreen.swift:238-240` then set `micDenied`/`showKeyboard` and never re-prompt. iOS itself doesn't re-prompt after a denial. ✅ On-device only: `requiresOnDeviceRecognition = true`. ✅
- **Whisper removed.** `git grep` for `ModelTier|ModelDownloader|RealBellowsController|BellowsEngine|BellowsHandle|whisper-rs|ggml` in `apps crates .github` (non-md, excluding generated `ffi.swift`) finds only comments (S4/N5). The deleted files are gone. `crates/ffi/Cargo.toml` drops the `whisper` feature. `Cargo.lock` drops whisper-rs, whisper-rs-sys, bindgen, clang-sys and similar. ✅
- **No Metal.** `Package.swift` links only `c++` and `Foundation` (`:38-41`). `build-ffi.sh` builds `--features goose` and hands each slice's plain `libffi.a` to `xcodebuild -create-xcframework`; `merge_slice` and the ggml loop are deleted. ✅
- **Empty-turn guard.** `commit` counts only words that contain alphanumerics (`text_bellows/mod.rs:157-169`). `finish_closing` and `end_turn_without_request` emit `UtteranceEnded` only when the turn's total word count is > 0, and otherwise bump `empty_turns` (`:172-182`, `:331-346`). Tests: `silence_only_turn_is_dropped_and_counted`, `punctuation_only_and_timed_out_empty_turns_are_dropped`, `words_before_a_rotation_still_count_for_the_turn`. Mutants M4a/M4b are caught (see §6). ✅
- **Rotation.** Soft rotation happens at 40 s when the endpointer is idle, hard rotation at 55 s regardless (`:93-94`, `:362-375`). Swift swaps the new request in before `endAudio` on the old one (`rotate(from:)`), so no audio is lost at the seam. Rotation closes don't count as self-closes. ✅
- **S1 (should-fix): the storm halt can trip on an ordinary pause.** `close_with` counts every self-close of an Active request whose committer saw no words. On the third one it halts for the whole session, emits `Unavailable` and Swift turns the mic off (`:298-312`).
  - The plan review proposed counting only self-closes "within 1 s of `begin_request`" (`bellows-apple-speech.REVIEW.md:217`). The plan dropped that window (`bellows-apple-speech.md:398`), so a slow self-close counts too.
  - If the on-device recognizer ends a quiet request by itself ("no speech detected"), three long thinking pauses kill the Bellows mid-session. So would a banked (muted) Bellows, which feeds no audio: `ingest` returns early when muted.
  - That recognizer behaviour is still marked UNVERIFIED (`bellows-apple-speech.md:134`), and the on-device measurement (Task 12) was not done (`BUILD-LOG.md:61`).
  - Fix: count only self-closes that arrive within ~1–2 s of `begin_request`, or skip counting while muted or idle. Add one turn test. Or, at minimum, check `self_closes` on the operator's phone with a 2-minute silent pause and a banked minute before an external tag.
- **tz at begin.** `RealEngineLoader.swift` passes `Int32(TimeZone.current.secondsFromGMT()/60)` to both `beginSession` and `beginInitiation`. `ffi/src/session.rs:153,169` calls `set_tz_offset_min` before any turn. `assemble_prompt` reads it every turn with `now = started_at` (`conductor.rs:245-256`). ✅
- Nit N3, pre-existing shape: if `stop()` runs while `start()` is still awaiting permission, the task resumes and starts capture after the stop, with the mic on and nobody listening. The window is tiny because the permission dialogs are modal.
- Nit N4: the locale is hard-coded to `en-US`. Whisper was `.en` too, so this is parity, not a regression.
