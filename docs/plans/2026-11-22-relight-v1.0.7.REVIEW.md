### Should-fix

**S1: Wrong CI root cause and a false commit body** (§1). Rewrite the Diagnosis, the Step-5 commit body and Risk #3.

**S2: The export only works when the real engine constructed, which needs a key.**

Its `exportVault()` returns demo text and `exportDatabaseCopy` returns false, so the operator would get "1 file" of demo markdown.
